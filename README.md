## 💬 ارسال پیام

برای ارسال پیام متنی می‌توانید از `send_message` استفاده کنید:

```python
client.send_message(
    chat_id="CHAT_ID",
    text="سلام از SPlus Client!"
)
```

پارامترهای اصلی:

- `chat_id` : شناسه چتی که پیام باید در آن ارسال شود.
- `text` : متن پیام.
- `reply_to` : در صورت نیاز، شناسه پیامی که باید به آن پاسخ داده شود.

## 👂 دریافت پیام‌های جدید

Client امکان دریافت پیام‌های جدید و اجرای یک Handler هنگام دریافت هر پیام را فراهم می‌کند.

نمونه:

```python
def on_new_message(update, chat_id, message_id):
    print("=" * 50)
    print("📩 پیام جدید")
    print("Chat ID:", chat_id)
    print("Message ID:", message_id)
    print("Update:", update)
    print("=" * 50)

    # دریافت متن پیام کاربر
    # این مسیر برای پیام‌های متنی استفاده می‌شود.
    message_text = update["message"]["content"]["text"]["text"]

    print("متن پیام:", message_text)

    # ارسال پاسخ به پیام کاربر
    client.send_message(
        chat_id=chat_id,
        text="تو گفتی: " + message_text,
        reply_to=message_id
    )


client.listen_for_updates(
    handler=on_new_message,

    # اگر True باشد، پیام‌های ارسال‌شده توسط خودمان
    # نیز به Handler برگردانده می‌شوند.
    self_messages=False,

    poll_interval=0.35
)
```

### دریافت متن پیام

برای پیام‌های متنی، متن پیام از مسیر زیر قابل دریافت است:

```python
message_text = update["message"]["content"]["text"]["text"]
```

برای مثال، اگر کاربر پیام زیر را ارسال کند:

```text
سلام خوبی؟
```

مقدار `message_text` برابر خواهد بود با:

```text
سلام خوبی؟
```

در مثال بالا برنامه در پاسخ ارسال می‌کند:

```text
تو گفتی: سلام خوبی؟
```

---

## 🔄 پارامتر `self_messages`

پارامتر `self_messages` مشخص می‌کند که پیام‌های ارسال‌شده توسط خودمان نیز به Handler برگردانده شوند یا خیر.

### غیرفعال

```python
self_messages=False
```

در این حالت پیام‌هایی که خود برنامه ارسال می‌کند به Handler برگردانده نمی‌شوند.

### فعال

```python
self_messages=True
```

در این حالت پیام‌های ارسال‌شده توسط خودمان نیز به Handler برگردانده خواهند شد.

این قابلیت در مواردی که نیاز به بررسی یا پردازش پیام‌های ارسال‌شده توسط خود برنامه دارید کاربرد دارد.

---

## ⏱️ پارامتر `poll_interval`

پارامتر `poll_interval` فاصله زمانی بررسی پیام‌های جدید را بر حسب ثانیه مشخص می‌کند.

برای مثال:

```python
poll_interval=0.35
```

یعنی Client تقریباً هر ۰٫۳۵ ثانیه وضعیت پیام‌های جدید را بررسی می‌کند.

## 🤖 ساخت ربات

با ترکیب دریافت پیام و ارسال پیام می‌توان ربات‌های مختلفی ایجاد کرد.

برای مثال:

```python
def on_new_message(update, chat_id, message_id):

    # دریافت متن پیام کاربر
    message_text = update["message"]["content"]["text"]["text"]

    if message_text == "سلام":
        client.send_message(
            chat_id=chat_id,
            text="سلام! 👋",
            reply_to=message_id
        )

    elif message_text == "خداحافظ":
        client.send_message(
            chat_id=chat_id,
            text="خداحافظ 👋",
            reply_to=message_id
        )


client.listen_for_updates(
    handler=on_new_message,
    self_messages=False,
    poll_interval=0.35
)
```

با استفاده از همین ساختار می‌توان منطق‌های پیچیده‌تر و ربات‌های کامل‌تری ایجاد کرد.
