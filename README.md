# SPlus Client 🇮🇷

یک Client پایتونی برای کار با سروش‌پلاس (SPlus) از طریق نسخه وب آن.

این پروژه با استفاده از Python و Selenium توسعه داده شده و با هدف فراهم کردن امکانات لازم برای ساخت ابزارهای اتوماسیون و ربات برای سروش‌پلاس ایجاد شده است.

> ⚠️ این پروژه رسمی نیست و توسط سروش‌پلاس توسعه یا پشتیبانی نمی‌شود.

## 👂 دریافت پیام‌های جدید

Client امکان دریافت پیام‌های جدید و اجرای یک تابع مشخص هنگام دریافت هر پیام را فراهم می‌کند.

نمونه:

    def on_new_message(update, chat_id, message_id):
        print("📩 پیام جدید")
        print("Chat ID:", chat_id)
        print("Message ID:", message_id)
        print("Update:", update)

        # دریافت متن پیام کاربر
        message_text = update["message"]["content"]["text"]["text"]

        print("متن پیام:", message_text)

        # ارسال پاسخ به پیام کاربر
        client.send_message(
            chat_id=chat_id,
            text="تو گفتی: " + message_text,
            reply_to=message_id
        )

    client.listen_for_updates(
        handler=on_new_message,

        # اگر True باشد، پیام‌های ارسال‌شده توسط خودمان
        # نیز به Handler برگردانده می‌شوند.
        self_messages=False,

        poll_interval=0.35
    )

متن پیام دریافتی از مسیر زیر قابل دسترسی است:

    update["message"]["content"]["text"]["text"]

در مثال بالا، متن پیام در متغیر `message_text` قرار می‌گیرد و سپس همان متن در پاسخ به پیام کاربر ارسال می‌شود.

برای مثال، اگر کاربر پیام زیر را ارسال کند:

    سلام خوبی؟

برنامه پاسخ زیر را ارسال می‌کند:

    تو گفتی: سلام خوبی؟

### پارامتر self_messages

- `False` : پیام‌های ارسال‌شده توسط خود برنامه به Handler برگردانده نمی‌شوند.
- `True` : پیام‌های ارسال‌شده توسط خودمان نیز به Handler برگردانده می‌شوند.

پارامتر `poll_interval` فاصله زمانی بررسی پیام‌های جدید را بر حسب ثانیه مشخص می‌کند.

این قابلیت می‌تواند برای پردازش خودکار پیام‌ها و توسعه ربات‌ها و ابزارهای اتوماسیون مورد استفاده قرار گیرد.

    selenium>=4.15.0
    requests>=2.31.0

    pip install -r requirements.txt

    python main.py
